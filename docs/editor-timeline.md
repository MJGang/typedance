# 时间轴排版

时间轴是通用内容容器，可用于工作经历、项目经历和教育经历。每个条目内可以继续使用已有的 H1–H3 标题、有序和无序列表、嵌套列表、分栏、分割线、对齐、行高，以及局部字号、颜色和加粗等格式能力。

## 插入与整理已有内容

打开简历格式工具栏，点击“时间轴”：

- “插入空白时间轴”创建两个空白条目，光标进入第一个条目。
- “所选内容转为时间轴条目”将连续同级内容放入同一个条目，保留原来的正文、格式和来源关联。
- 整段工作经历转换后，将光标放在第二家公司所在的段落，在条目菜单中选择“从当前段落拆出新条目”。该段及后续内容会移动到新条目，重复此操作可拆分多段经历。首段不能再次拆分。

例如，公司名称、岗位和日期可以放在条目内的三栏表头中，工作内容使用下方的无序列表；也可以在条目内继续添加独立标题和多级列表。

## 条目与整体操作

悬停条目或在条目内编辑时，左侧显示操作菜单。支持在前后新增条目、删除条目及正文、删除整个时间轴及正文，以及“取消时间轴，保留正文”。这些操作均可撤销和重做。

删除最后一个条目后恢复普通空段落。“在时间轴后继续输入”可在容器后插入普通段落，继续编辑其他章节。

## 保存与导出

正文宽度随页面或所在分栏调整，高度由内容撑开。装饰不参与正文编辑，首项使用实心圆，其余使用空心圆，连线延伸到最后一个圆点。

时间轴与正文一起保存在画布文档中。分页器在节点挂载、内容高度或字体变化后重新测量；跨页连线避开页边距和页间空白。HTML/PDF 导出沿用画布的静态打印快照，移除操作菜单，保留正文与装饰。

通过 MCP 或文档 API 从已保存的画布导出，也会保留时间轴、标题、列表、分栏和局部格式；后台导出沿用自然分页，画布按钮导出保留当前测量的分页位置。
