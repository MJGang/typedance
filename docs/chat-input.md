# 聊天语音与附件

## 职责与数据

- `harness-contracts` 定义通用附件结构；`harness-core` 定义独立于 Agent Run 的语音 Provider 接口和音频约束，复用已有多模态消息。
- `harness-speech` 提供可复用的 SenseVoiceSmall INT8 / Silero VAD 本地适配器，负责固定版本资源的下载校验、原生子进程、推理取消与空闲释放，不依赖工作区、简历或 Python。
- Agent Host 保存语音偏好、提供受会话令牌保护的设置与转写接口，将聊天附件持久化并投影成模型消息。录音只在内存中短暂存在，不写入对话、Run 或观测事件。
- Frontend 负责麦克风授权、PCM 采集、实测音量波形、草稿与附件卡片；Sidecar 只负责确定性的文档文本提取，不接入语音模型或 AI 编排。

## 使用与限制

在“设置 → 语音输入”选择语言和下载源，下载约 241 MB 的固定版本模型。完成后无需语音 API Key，音频不离开本机；聊天大模型仍按现有配置运行。支持自动、中文、英语、粤语、日语和韩语。

录音最长 120 秒，停止后转写并追加到当前草稿，用户确认发送。转写失败会释放麦克风并在内存中保留录音，允许重试。取消、Escape、页面隐藏、切换对话、面板卸载会终止操作、清除录音并释放设备。麦克风授权或转写迟到时不会向其他对话写入。静音不会产生消息。

图片、文件可粘贴、拖放或通过“添加”选择。每条消息最多 6 个附件，单文件不超过 10 MiB，附件 JSON 总传输不超过 7 MB，文档提取文本不超过 12 万字符。PNG、JPEG、WebP、GIF 通过图片消息传给支持视觉的模型；PDF、Word、Markdown、常见文本和代码文件提取为纯文本。不支持的二进制、空文件、扫描文档或超限文本会明确拒绝，不截断内容。PDF/Word 的原始布局和内嵌图片不作为视觉附件发送，需阅读图表时另附图片。

附件卡片和已提取文本或图片随消息保存在本机 Agent Host 数据中，重开对话继续可见；未发送草稿在当前面板的对话切换间分别保留。附件不是工作区长期上下文引用，不会读取或删除用户原始文件。

## 本地模型与桌面交付

模型位于应用数据目录的 `speech/sensevoice-small-int8/`，偏好位于 `agent-host/speech.json`。下载使用固定 revision、文件大小和 SHA-256，完整文件可复用，取消或校验失败时清除未完成文件。来源由用户明确选择，不自动改发到其他语音服务。

推理最多接收一个任务；超时或取消会终止并等待独立识别进程退出。IPC 使用结构化二进制传输，子进程不监听网络端口。原生推理崩溃不会退出 Host；与 Host 断开连接时子进程自行退出。空闲 60 秒释放模型内存，下一次识别重新加载。Windows x64 安装包单独包含 `speech-runtime` 原生库，不包含预下载模型。构建时用真正的 SEA Host 验证原生模块加载；安装冒烟继续验证安装后的运行库路径。

## 验收

检查取消与对话切换后的资源释放、迟到结果、录音停止的最终音频块、发送失败的草稿保留、附件历史恢复、图片和文本模型请求结构、超限与损坏输入，以及下载完整性。另用浏览器真实 AudioWorklet 与固定语音样本验证转写，使用当前可用聊天凭据验证图片和文件内容。浏览器自动化使用固定音频设备时，不等同于用户实体麦克风验收。
