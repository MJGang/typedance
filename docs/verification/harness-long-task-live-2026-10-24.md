# Harness 长任务实模验证

日期：2026-10-24。测试源码提交：`affb38aa6c7d3fab63207816f46b9118cbf43ab9`。

本次使用真实 DeepSeek 服务与 `deepseek-v4-flash` 模型执行。测试凭据由父进程通过子进程 stdin 临时注入，只供本次测试进程使用，未写入仓库、配置或测试记录。之前使用已有配置返回 401 的尝试不计为成功验证；本记录对应补充凭据后实际完成的运行。

## 任务与判定

目标是通过工具顺序完成全部 12 个合成步骤，然后读取权威状态确认计数为 12。

- `live.status` 返回当前完成数、下一步编号和随机校验值。
- `live.advance` 必须同时提供正确的下一步编号与当前随机校验值。每次成功执行都会换一个随机值，因此模型不能预先批量生成后续正确调用。
- 每次推进返回较长的合成证据，输入预算设为 10,000，达到 50% 时触发模型摘要，主动覆盖多次压缩交接。
- 完成检查回调只在 12 个步骤全部完成且模型调用 `live.status` 核验最终状态后允许结束。检查不通过时返回缺失事项并继续执行。
- 只使用合成数据，不修改用户简历或本地资料。

## 证据边界

本次验证证明真实模型可以通过当前 Core 执行超过八轮的任务，并跨多次摘要交接达到确定性验收条件。它使用较短的合成任务及外部完成检查，不证明任意业务任务都会自行识别全部验收条件，也不证明数小时运行的成功率。

本次未执行真实业务文档修改或实模进程恢复。进程中断、已完成工具不重放、结果不确定的调用处理、权限等待和取消等能力由此前的 Core 行为测试及双进程 Host HTTP/SSE 测试分别覆盖。
