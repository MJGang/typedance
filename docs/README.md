## 文档管理原则

1. 当前要实现的范围写入 `requirements.md`。
2. 暂不实现但方向正确的想法写入 `product-vision.md`。
3. 被替换的历史文档移入 `archive/`，不要删除。
4. 新增重要产品方向前，先判断属于 V1 需求、后续路线，还是长期愿景。
