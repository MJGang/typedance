- AI 可读取当前画布结构、查看页面，并按当前可用能力修改内容与排版。
- 支持个人信息和教育经历四栏、工作标题按统一百分比三栏、时间右对齐，以及文字强调、列表、页面边距和当前简历模板样式调整。
- 手动确认模式提供整批修改预览与撤销；自动修改模式在当前简历授权范围内执行。原文或编辑会话变化时会阻止过期修改。
- 文档样式、分栏宽度、页边距和模板覆盖统一保存到后端，复制、重开和导出保持排版。旧浏览器页边距先备份再一次性迁移。
- 修复结构调整后原文引用定位与撤销恢复，覆盖分栏换序、无 ID 段落、重复文字、列表转换和文字拆栏；未产生变化的操作不会撤销此前编辑。
- 手动工具栏与 AI 共用后端编辑能力；标题与连续正文可合并成同一个列表，栏对齐覆盖嵌套列表，分隔线插入到当前内容块之后并保留选中文字。
- 提供 Windows x64 安装包及签名更新清单，可从“设置 → 客户端更新”升级到 0.1.3。
