登录前即可自动更新 TypeDance，无须进入工作台设置。

- 登录窗底部以单行显示当前版本和更新状态，细进度条贴合窗口底边；不增加更新卡片或操作按钮。
- 发现新版本后自动下载并校验签名，下载完成后自动安装、重启，无须点击确认或选择稍后。
- 登录尚未完成时会先取消授权并等待本机回调清理；历史数据导入已开始时等待导入结束。进入工作台后则先暂停任务、保存画布，保存失败不启动安装。
- 网络检查或下载失败时按 10、30、60 秒有限重试；仍失败会显示状态，登录入口保持可用。安装失败不会重复弹出安装器。

同时保留 GitHub 登录与历史数据导入修复：

- 登录验证通过后，在界面选择一份历史数据导入，或选择“暂不导入，进入工作台”；无需设置环境变量。
- 历史数据包括简历、画布、参考文件、AI 对话及设置。导入需要用户明确确认，保留原数据备份，不自动合并多个目录；已归属其他账号的数据无法导入。
- Windows 账号认证请求支持系统代理，并区分网络连接、服务响应和配置校验错误。
- 浏览器登录等待延长到 10 分钟，收到回调后完整发送提示页再关闭监听，取消或超时后释放端口。

账号服务配置方式见[配置说明](https://github.com/MJGang/typedance/blob/v0.1.18/docs/account-setup.md)。业务数据仍按账号保存在本机，模型 API Key 由用户自行提供。
