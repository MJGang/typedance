本版本新增强制登录。首次使用请先按[账号服务配置说明](https://github.com/MJGang/typedance/blob/v0.1.15/docs/account-setup.md)配置 Logto 租户与第三方连接器；未配置时停留在登录提示，不启动业务服务。

- 新增可配置的微信、Google、GitHub 登录，支持注册、退出和切换账号。
- 登录页采用独立小窗口与项目原图标，微信为首选黑色按钮。
- 工作台左下角常驻显示头像、昵称和登录状态，点击即可管理账号安全、打开设置、切换账号或退出登录。
- 简历、资料、对话与模型设置按账号在本机独立管理；模型 API Key 保存在 Windows 凭据管理器，AI 费用仍由用户自行承担。
- 退出或切换前先结束账号活动并保存画布，保存失败时保留当前工作区和重试入口。
- 首次升级发现未归属的本机资料时，由用户明确认领后再迁入账号，原资料保留备份；不提供云同步。
- 空白工作台增加“新建简历”入口，复用现有创建、导入流程，并防止迟到的列表结果打断输入。
- 改善头像缺失、长昵称、深色模式、窄窗口与设置窗口的键盘焦点体验，保留客户端更新提醒。
- 修复打包后的 Python 服务因入口导入失败而无法启动的问题，并保留启动错误供构建检查定位。
