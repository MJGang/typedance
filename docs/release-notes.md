修复新安装客户端提示“账号服务尚未配置”、无法显示登录按钮的问题。

- 正式安装包内置官方公开登录配置，新安装或本机配置文件不存在时，也能直接显示已启用的 GitHub 登录入口。
- 发布环境缺少登录地址、Native 应用 ID 或可用渠道时直接停止构建，避免再次发布缺配置的安装包。
- 增加无本机配置文件、无运行时登录配置变量的干净安装验收，验证内置配置、登录渠道和登录前的业务服务门禁。
- 保留 v0.1.19 的本地服务令牌修复，以及登录窗底部自动下载、安装和重启更新的交互；不需要清空本机资料。

账号服务配置方式见[配置说明](https://github.com/MJGang/typedance/blob/v0.1.20/docs/account-setup.md)。业务数据仍按账号保存在本机，模型 API Key 由用户自行提供。
