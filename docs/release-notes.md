- AI 聊天支持本地语音输入：录音波形、取消录音、停止后转写并填入草稿；切换对话和关闭面板会释放麦克风，取消结果不会进入其他对话。
- 设置新增“语音输入”：选择识别语言和模型下载源，查看下载进度、取消与重试。SenseVoiceSmall INT8 与 Silero VAD 在本机 CPU 上识别，无需语音 API Key 或按次付费，首次下载约 241 MB，随后离线使用。
- 聊天输入框支持粘贴、拖放和选择图片、PDF、Word、Markdown、文本及代码文件，发送前显示可移除的附件卡片，发送后随对话保存并供模型读取。
- 服务端校验附件格式、大小和数量；无法提取文本的文件与超限附件明确提示，避免静默丢失内容。
- Windows 安装包包含语音原生运行库，提供签名更新清单，可从“设置 → 客户端更新”升级到 0.1.4。
