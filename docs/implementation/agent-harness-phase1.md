# Agent Harness 第一轮可靠性优化

## 行为与边界

- Harness Core 为每个 run 管理取消信号，向模型和工具传递；取消后立即停止等待，不再启动后续调用，终态幂等且不可重新打开。忽略信号的工具不会阻塞会话锁，也不会向已结束的运行追加迟到结果；工具自身的外部副作用仍须由实现方响应信号和保证幂等。
- Agent Host 在上下文准备期间也响应取消；同一会话的执行互斥，重复发送和执行中的删除返回 409。提供活动运行查询，便于页面恢复订阅。
- 画布与每份显式引用分别形成带来源、裁剪信息的上下文片段，按权重分配总计 24000 字符的上下文资料预算，单片段最多 12000 字符。该预算针对资料片段，尚不包含历史对话或模型 token 预算。
- 前端通过 Authorization 请求 HTTP 和 SSE；流断开后读取服务端状态、补齐 sequence 后的事件并重连，不生成本地 run_failed。会话切换和卸载会关闭订阅，迟到响应不覆盖新会话。
- 本机 Host 仅接受 loopback Host 与明确允许的桌面/Vite Origin。可信 Origin 可获取进程随机令牌，业务接口验证 Bearer；健康检查保持公开。JSON 请求上限 1 MiB。

默认可信来源包含 Windows Tauri 的 http://tauri.localhost、https://tauri.localhost、tauri://localhost，以及 Vite 的 http://127.0.0.1:5173、http://localhost:5173。测试或嵌入场景通过服务构造参数明确指定 allowedOrigins；令牌不放入 URL、不持久化到前端存储。

## 验证

- 执行仓库统一 verify:change：全量构建、应用测试、6 项验证脚本测试和 14 项发布脚本测试通过；最终提交的全量结果以 PR 的 Windows CI 为准。
- 对评审及收尾补丁，重新通过 28 项 Core、37 项 Host、45 项相关前端测试，并重新构建。
- 改动涉及的前端文件通过 ESLint。
- 隔离端口和数据目录进行真实 Edge 浏览器验收，模型使用模拟 Adapter：主动断开 SSE 后显示重连，连续片段无重复或遗漏；取消后为 cancelled，事件数保持 6，不再增长。
- 未调用真实模型服务，未打发布标签或发布客户端。
- 自动评审补充覆盖：工具忽略取消信号时仍释放会话，以及发送过程中清空会话、加载消息时切换会话时忽略旧结果。
