# WP2 Storage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 sidecar 能保存 Revision Engine 的核心领域对象，为后续 WP3 services、WP8 API 和 WP9 WorkspaceView 提供本地优先存储基础。

**Architecture:** 保留现有 legacy `resume_versions/template_*` 表和 repository，不破坏当前编辑与导出闭环；新增 `typedance_sidecar.revision_models` 定义 Pydantic 领域对象，新增 `typedance_sidecar.revision_repository` 提供按领域表保存、读取、按 document 查询的 repository。SQLite 采用“分表 + payload JSON + schema_version + created_at/updated_at”的过渡结构，避免单表大 JSON，同时让后续服务层可以逐步展开索引字段。

**Tech Stack:** Python 3.14, Pydantic v2, SQLite, pytest.

**Execution Status:** 已在 `codex/wp2-storage` 分支完成首批存储层落地和验证。验证命令：`corepack pnpm --filter @typedance/sidecar test -- tests/test_revision_repository.py`、`corepack pnpm --filter @typedance/sidecar test`、`corepack pnpm test`。
