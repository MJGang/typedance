# AI 聊天流式滚动设计

## 目标

AI 回复流式输出时，在用户仍停留于消息底部的前提下持续跟随最新内容；用户主动向上阅读历史消息后，不再强制拉回底部。

## 交互规则

- 消息容器距离底部不超过 24px 时，视为处于自动跟随状态。
- 自动跟随状态下，流式消息内容增长后立即贴到底部，避免逐 token 平滑动画叠加造成抖动或闪屏。
- 用户滚动并离开底部后，暂停自动跟随，在消息区域底部中央、输入框上方显示向下箭头按钮。
- 用户点击向下箭头后，执行一次平滑滚动到最底部；抵达底部后恢复自动跟随并隐藏按钮。
- 用户自行滚回底部时，同样恢复自动跟随并隐藏按钮。
- 切换会话或首次加载消息时直接定位到底部，不播放长距离滚动动画。

## 实现边界

改动仅属于 Frontend：在 `AgentChatPanel` 内管理消息容器滚动状态，不改变 Agent Host、Harness Core、Python Sidecar 或事件协议。

消息容器使用 DOM ref 读取 `scrollTop`、`scrollHeight` 与 `clientHeight`。滚动监听只更新“是否跟随底部”这一布尔状态；流式消息渲染完成后，仅在该状态开启时设置容器滚动位置。向下箭头复用项目现有 `Button` 与 Lucide 图标。

## 验证

- 回归测试覆盖：流式增量到达时，处于底部会继续滚到底部。
- 回归测试覆盖：用户向上滚动后，流式增量不改变滚动位置并显示向下箭头。
- 回归测试覆盖：点击箭头使用平滑滚动，并在回到底部后恢复自动跟随。
- 运行 `AgentChatPanel` 定向测试与 Web 构建。
