# 简历修订工作台标题栏与工具栏精简设计

## 背景

当前简历修订工作台在左侧导航顶部与编辑器工具栏上方重复展示工作区标题，返回、标题编辑和导出操作又集中在额外标题栏中，造成纵向空间浪费和信息重复。此次调整将工作区级导航归入左侧栏，将文档操作归入编辑器工具栏，并删除重复标题栏。

## 目标

- 左侧导航顶部作为唯一的工作区标题展示与编辑入口。
- 返回简历工作区列表的入口位于左侧导航标题行右端。
- 删除编辑器工具栏上方的整条工作区标题栏，不保留占位高度。
- 导出入口移入编辑器顶部格式工具栏，并采用与现有工具一致的纯图标样式。
- 工作区标题最多允许 10 个字符，编辑时显示 `x/10` 字数提示。

## 信息架构与布局

### 左侧导航标题区

左侧导航顶部改为单行标题区：

- 左侧为可截断的工作区标题和铅笔编辑图标。
- 右侧为返回图标按钮，行为沿用现有逻辑，返回简历工作区列表。
- “工作区”辅助文案删除，避免与标题重复占用空间。
- 标题区域与返回按钮保持明确的点击边界；标题或铅笔图标进入原地编辑，返回按钮只执行导航。

### 标题编辑

- 编辑态在标题区内显示输入框。
- 输入最多 10 个字符，并在输入框附近显示实时 `x/10`。
- `Enter` 或失焦提交，`Escape` 取消，沿用现有保存接口和错误恢复逻辑。
- 空标题不提交，恢复为服务端当前标题。
- 保存失败时保留编辑态和错误提示，并重新聚焦输入框。
- 字符计数按 JavaScript 字符串的可见 Unicode 字符序列计算，避免中文标题被按字节计数；输入层与提交层都执行 10 字符约束。

### 编辑器顶部工具栏

- 删除 `RevisionWorkspacePage` 中位于画布上方的独立工作区标题栏。
- 导出入口追加到现有富文本格式工具栏最右侧，以弹性留白与格式操作分开。
- 导出入口使用与现有工具栏一致的图标按钮尺寸、悬停态、焦点态和分隔方式，不显示“导出”文字。
- 默认显示下载图标，悬停提示“导出”；点击后展开“导出 PDF”和“导出 HTML”菜单。
- 导出期间按钮禁用并显示旋转加载图标，不改变工具栏高度和横向布局。
- 导出仍使用当前画布内容、页边距和模板样式，不改变导出业务逻辑。

## 组件与数据流

- `RevisionWorkspacePage` 继续拥有工作区数据、标题保存状态和导出状态，避免把业务请求下沉到纯展示组件。
- `WorkbenchSidebar` 新增标题编辑与返回相关回调及状态参数，负责渲染标题区和触发用户意图。
- `DraftCanvas` 与 `ResumeRichTextEditor` 增加可选的工具栏尾部操作插槽，将导出菜单注入现有工具栏；通用编辑器不感知“工作区”或具体导出业务。
- 标题更新成功后由页面更新工作区状态，左侧标题立即同步。
- 导出菜单只向页面回传格式选择，实际导出仍由页面现有 `handleExport` 执行。

这一边界保持 `Frontend` 内部职责清晰：页面协调业务状态，侧栏和编辑器只负责交互展示，不涉及 Harness、Agent Host 或 Python Sidecar 架构变更。

## 可访问性与视觉规范

- 所有图标操作使用现有 shadcn `Button`、`DropdownMenu` 和工具栏按钮模式，不使用自定义 `div` 点击区。
- 返回、编辑和导出图标均提供明确的 `aria-label` 与 Tooltip。
- 键盘用户可以聚焦并触发全部操作，焦点样式沿用当前设计系统。
- 图标使用项目现有 Lucide 图标集，尺寸和颜色继承工具栏规则。
- hover 只改变颜色或背景，不使用导致布局抖动的缩放效果。

## 错误与边界处理

- 标题保存中禁用重复提交。
- 标题超过 10 个字符时在输入和提交两层截断，避免粘贴或程序赋值绕过限制。
- 导出不可用或进行中时禁用导出图标及菜单项。
- 标题保存失败与导出失败继续使用现有错误提示方式，不新增兼容分支或旧入口。

## 测试与验收

- 断言独立工作区标题栏已删除，页面不再出现重复标题。
- 断言左侧标题区包含编辑入口和返回按钮，返回按钮导航至简历工作区列表。
- 断言标题输入显示 `x/10`、最多接受 10 个字符，并正确提交、取消与处理保存失败。
- 断言导出图标位于富文本工具栏中且页面不显示文字型“导出”按钮。
- 断言导出菜单仍可选择 PDF/HTML，并携带当前画布、页边距和模板样式。
- 运行相关 Vitest 测试、Web 测试与 Web 构建；最后在实际页面验证标题区、工具栏位置、菜单与纵向空间变化。

## 非目标

- 不改变 PDF/HTML 导出格式、文件命名或 Sidecar 导出接口。
- 不调整左侧导航其余上下文、对话、插件和设置结构。
- 不修改简历画布内容、分页、页边距或 AI 对话面板行为。
