# 对话标题与操作入口优化设计

## 目标

精简工作台标题栏，统一当前对话与对话列表的操作入口，使置顶、重命名和删除行为清晰可见，并避免无效的占位标题与说明文字。

## 架构边界

本次改动属于 Frontend 与 TS Agent Host 的既有职责范围：

- Frontend 负责菜单、按钮、重命名弹窗、删除确认弹窗和当前选择状态。
- TS Agent Host 继续通过现有对话更新与删除接口持久化 `name`、`pinned` 及删除操作。
- Harness Core 与 Python Sidecar 不参与本次改动。

页面层统一协调当前对话的操作和刷新，`AgentChatPanel` 只展示当前对话标题与菜单并触发回调，不直接维护工作区级对话列表状态。

## AI 面板标题栏

- 选择对话后，标题栏显示对话标题和“…”菜单按钮。
- 菜单包含“置顶对话”或“取消置顶对话”，以及“重命名对话”。
- 未选择对话时，不显示标题和“…”菜单按钮，标题区域保持为空。
- 删除标题下方的“会话”“新建或选择会话”等解释文字。
- AI 运行状态和隐藏面板按钮保持现有行为。

## 对话列表

- 对话项默认继续显示标题、运行状态、置顶状态和时间信息。
- 时间信息贴齐条目右侧，不为未显示的操作按钮预留空白。
- 悬停条目时隐藏时间信息，并在原位置展示操作按钮。
- 已置顶状态使用实心图钉；“取消置顶对话”使用空心图钉，“置顶对话”使用实心图钉。
- 鼠标悬停某个对话时，在条目右侧从左到右显示“…”按钮和重命名按钮。
- “…”菜单只包含“置顶对话”或“取消置顶对话”，以及“删除对话”。
- 移除现有悬停置顶按钮和直接删除按钮，避免同一操作出现多个入口。
- 重命名按钮直接打开重命名弹窗。
- 保留双击对话项重命名行为，作为既有快捷操作。

## 重命名与删除

- AI 面板菜单与对话列表重命名按钮使用同一种重命名弹窗和保存行为。
- 保存成功后刷新对话列表与当前对话标题；空名称不可保存。
- 删除对话必须先弹出二次确认框，明确显示将删除的对话标题。
- 删除成功后刷新对话列表。
- 如果删除的是当前对话，同时清空当前对话选择；AI 面板标题区域随即变为空。
- 更新或删除失败时使用现有 toast 反馈，不修改本地状态为成功结果。

## 工作区标题

- 移除工作区标题旁仅含一个菜单项的“…”下拉菜单。
- 改为直接显示重命名按钮，使用铅笔图标和明确的无障碍标签。
- 点击后继续打开现有工作区重命名弹窗，保存逻辑不变。

## 测试与验收

- `AgentChatPanel`：验证已选与未选对话时的标题和菜单显隐，以及菜单回调和置顶文案切换。
- `WorkbenchSidebar`：验证悬停操作顺序、重命名入口、“…”菜单内容、置顶文案切换和删除确认。
- `RevisionWorkspacePage`：验证重命名、置顶、删除后的刷新与当前选择同步，以及工作区直接重命名按钮。
- 运行相关前端单测、完整 Web 测试与 Web 构建。
- 验收时确认菜单、弹窗、按钮顺序和未选择对话状态与设计一致。
