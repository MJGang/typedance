# 工作台左右面板可拖拽宽度设计

## 背景

修订工作台当前采用固定三栏布局：

- 左侧 `WorkbenchSidebar` 固定为 `17rem`。
- 中间为自适应简历画布。
- 右侧 `AgentChatPanel` 固定为 `24rem`，并支持显示或隐藏。

固定宽度无法适应不同窗口尺寸、上下文内容和对话阅读需求。本次改动让左右面板都能通过分隔条调整宽度，并在本机保留用户选择。

## 目标

- 左侧工作台导航面板和右侧 AI 面板均可水平拖拽调整宽度。
- 调整过程中保持中央画布可用，不允许侧栏无限挤压画布。
- 用户调整后的宽度在本机持久化，下次打开任意修订工作台时恢复。
- 保持现有面板显示、隐藏、对话选择和画布滚动行为不变。
- 提供键盘可操作的分隔条。

## 非目标

- 不同步面板宽度到服务端或工作区业务数据。
- 不为不同文档分别保存宽度。
- 不改变面板显示、隐藏状态的持久化方式。
- 不引入新的面板布局依赖。
- 不修改 Agent Host、Python Sidecar 或 Harness Core。

## 方案选择

采用 Frontend 内部的自定义拖拽分隔条和宽度状态，不新增依赖。

备选方案包括引入通用可调整面板库，以及使用 CSS `resize`。通用库对当前两个分隔条而言引入面偏大；CSS `resize` 难以统一处理中央画布最小空间、双侧联动、键盘操作和持久化，因此不采用。

## 组件与状态归属

`RevisionWorkspacePage` 继续作为三栏布局的唯一所有者：

- 保存左侧和右侧面板的当前像素宽度。
- 根据容器宽度计算拖拽边界。
- 向布局应用宽度。
- 在拖拽结束时写入本机存储。
- 保持 `WorkbenchSidebar` 和 `AgentChatPanel` 专注于各自内容，不让它们拥有外部布局状态。

新增一个小型、通用但仅在 Frontend 使用的分隔条组件或 hook，负责：

- `pointerdown` 后捕获指针。
- 根据指针位移计算候选宽度。
- 将候选宽度限制在允许区间。
- 在拖拽结束或取消时清理状态和事件。
- 支持键盘左右方向键调整。

## 布局与尺寸规则

- 左侧默认宽度：`17rem`。
- 右侧默认宽度：`24rem`。
- 左侧允许范围：`220px` 至 `420px`。
- 右侧允许范围：`320px` 至 `560px`。
- 中央区域需要保留最小可用宽度；当窗口不足时，动态收紧侧栏的实际最大宽度。
- 左侧面板隐藏时，不渲染左侧分隔条。
- 右侧面板隐藏时，不渲染右侧分隔条；重新显示后恢复此前保存的右侧宽度。

外观上，分隔条使用较宽的透明命中区和细分隔线：

- 默认视觉保持接近当前边界。
- 悬停、键盘聚焦或拖拽时提高分隔线对比度。
- 鼠标指针使用 `col-resize`。
- 拖拽期间禁用文本选择，避免画布或对话内容被误选。

## 持久化

面板宽度保存为本机全局工作台偏好，使用带版本语义的独立 `localStorage` 键。

- 初始化时读取并验证数值。
- 无效、缺失或超出范围的值回退到默认宽度并进行边界修正。
- 拖拽和键盘调整时实时更新 React 状态。
- 交互结束后再写入存储，避免在高频 `pointermove` 中反复写入。

该偏好仅属于界面布局，不进入工作区数据、文档数据或 AI 上下文。

## 可访问性

每个分隔条使用 `role="separator"`，并声明垂直方向分隔语义和当前宽度：

- 可通过 Tab 聚焦。
- 左右方向键按固定步长调整宽度。
- `Shift` 加方向键使用更大步长。
- 暴露 `aria-valuemin`、`aria-valuemax` 和 `aria-valuenow`。
- 提供明确的中文 `aria-label`，区分左侧面板和 AI 面板。

## 异常与边界处理

- 容器尺寸在拖拽过程中变化时，以最新边界重新限制宽度。
- `pointercancel`、窗口失焦或组件卸载时结束拖拽并恢复页面文本选择。
- 本机存储不可用时仍保持当前会话内可拖拽，不影响工作台使用。
- 读取到损坏的存储值时静默回退，不向用户展示错误提示。

## 测试与验证

组件测试覆盖：

- 默认宽度正确应用。
- 本机保存值可在初始化时恢复。
- 左右分隔条拖拽方向正确。
- 宽度不会突破各自最小值、最大值及中央区域约束。
- 拖拽结束后写入存储。
- 键盘方向键可调整并持久化宽度。
- 面板隐藏时对应分隔条消失，重新显示后恢复原宽度。
- 现有显示 AI 面板、隐藏 AI 面板和选择对话行为不回归。
