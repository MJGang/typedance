# TypeDance 工作台重建设计

> 日期：2026-05-12
> 状态：待评审
> 范围：页面路由、导航、首页、模板库、工作台、AI 交互、模板派生

## 背景

当前工作台（Workspace）布局中，右侧 InsightPanel 承载 AI 建议、质量指标等内容，左侧 ResumeCanvas 承载编辑器和操作按钮。模板样式配置（StylePanel）仅在独立的 TemplateDetail 页面中存在。页面切换通过 `activeSection` 状态控制，无路由系统。

目标是将简历编辑流程从"编辑器先行"改为**模板先行**：先选模板、预览、应用到简历，再进入工作台编辑内容和调整样式。

## 页面结构

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 首页 | 用户简历列表（缩略图网格） |
| `/templates` | 模板库 | 浏览/预览模板，应用到已有简历 |
| `/workspace/:id` | 工作台 | 编辑器 + 右侧 Tab 面板（样式/AI） |

引入 react-router-dom v6 实现路由。

### 首页 → 工作台路径

1. 首页点击「+新建简历」→ 弹窗展示模板列表 → 选择模板 → 创建简历 → 路由到 `/workspace/:id`
2. 首页点击已有简历缩略图 → 直接路由到 `/workspace/:id`
3. 模板库点击「应用」→ 应用到指定简历 → 路由到 `/workspace/:id`

## 首页 `/` — 我的简历

### 布局

- 页面标题：「我的简历」
- 右上角：「+新建简历」按钮
- 卡片网格：A4 比例缩略图

### 简历卡片

每个卡片展示：
- A4 比例缩略图区域（210:297 ≈ 3:4），有 PDF 预览截图的显示截图，无预览的用模板名称灰底占位
- 卡片底部：简历标题、目标岗位语言（zh-CN / en-US）、相对更新时间
- 右上角 `⋮` 菜单：重命名、复制、删除

空态：居中展示引导文案 + 「创建第一份简历」按钮跳转模板弹窗。

### 新建简历流程

点击「+新建简历」→ 弹窗（Modal），内部以卡片网格形式展示模板列表 → 每个模板卡片有「应用」按钮 → 点击后创建简历 → 路由到 `/workspace/:id`。

弹窗底部有「去模板库浏览更多」链接跳转 `/templates`。

## 模板库 `/templates` — 浏览模板

### 布局

- 页面标题：「模板库」
- 模板卡片网格，与当前结构一致

### 应用逻辑

每个模板卡片有一个「应用」按钮，点击后：
1. 弹窗让用户选择要应用到哪个已有简历，或创建新简历
2. 确认后路由到 `/workspace/:id`

（V1 可以先简化：直接创建新简历并路由）

### 编辑器区域

- 顶部工具栏：保存版本、导出 PDF 按钮
- 中间：TipTap 编辑器，全宽
- 底部：AI 操作按钮行（润色、优化等），点击后触发 AI 交互

### 右侧 Tab 面板

面板可折叠收起（点击 Tab 图标或面板边缘），收起后编辑器获得全宽。

#### 样式 Tab

- 预设选择器（经典/现代/简洁/商务）
- 块选择器（h1/h2/h3/p/ul/ol）
- 高频属性工具栏（字体、字号、加粗、颜色）
- 下方折叠属性区（间距、边框、列表缩进等）
- 保存状态指示

#### AI 助手 Tab

- 对话历史列表
- 建议结果展示（接受/编辑后接受/重新生成/拒绝 操作）
- 底部输入框 + 发送按钮
- 未读消息小红点标识
- 从 popper 钉来的内容高亮

## AI 交互模型

两种存在方式，用户可自由切换：

### 方式 1：浮动弹窗（Popup Mode）

- 选中编辑器中的文本 → 弹出小 popper，包含快速操作：
  - ✨ 润色
  - 📝 改写
  - 🔍 语法检查
  - 💬 自定义提问
  - 📌 钉到侧栏
- 点击操作后，弹窗展开为可拖拽浮动窗口，展示结果
- 窗口可拖拽到任意位置
- 窗口底部有「钉到侧栏」按钮

### 方式 2：钉到侧栏（Dock Mode）

- 从 popper 点「钉到侧栏」→ 右侧 AI 助手 Tab 激活
- AI Tab 标记未读小红点
- 对话记录保留在 Tab 中，支持持续对话
- 从 Tab 可「弹出」恢复为浮动窗口

## 模板派生模型

| 场景 | 应用时引用 | 第一次修改样式 | 后续修改 |
|------|-----------|---------------|---------|
| 内置模板（预设） | 指向预设模板 | fork → 创建用户模板副本 | 更新用户模板 |
| 用户模板（非预设） | 指向用户模板 | 直接更新当前模板 | 直接更新当前模板 |

### 实现要点

- 内置模板标记 `is_built_in: true`，前端显示为只读蓝本
- 用户模板在侧栏中显示为「我的模板」分组
- fork 时复制所有 block styles 到新模板记录
- 简历的 `template_id` 在 fork 后更新为派生模板 ID
