# 编辑器辅助控件显隐与全文复制设计

## 背景

旧简历重构工作台当前默认展示富文本格式工具栏、模块大纲和右侧分页器。它们有助于精细排版和快速定位，但会让样式调整在主界面中显得过于突出。产品的核心应继续聚焦于简历内容优化，样式编辑仅作为低频辅助能力按需出现。

本次改动只涉及 Frontend 展示与交互状态，不修改 Harness Core、TS Agent Host、Python Sidecar、业务数据结构或持久化协议。

## 目标

- 在画布标题栏增加格式工具栏显隐按钮。
- 格式工具栏默认隐藏；显示时，标题栏按钮进入激活状态。
- 模块大纲默认隐藏。
- 在格式工具栏中增加分页器显隐按钮，分页器默认隐藏。
- 在画布标题栏增加复制按钮，复制当前整份简历的纯文本内容。
- 每次进入工作台或切换文档时，格式工具栏、模块大纲和分页器都恢复为隐藏状态。

## 非目标

- 不提供 Markdown 复制或 HTML 富文本复制。
- 不持久化任何显隐选择。
- 不调整现有格式工具本身的功能、顺序或视觉样式。
- 不修改分页测量、页面跳转或大纲定位逻辑。
- 不把低频样式能力扩展成新的侧栏、弹窗或独立排版模式。

## 方案选择

### 方案 A：页面与画布局部状态控制

由 `RevisionWorkspacePage` 管理格式工具栏是否显示，因为标题栏按钮位于该组件；由 `DraftCanvas` 管理大纲和分页器是否显示，因为两者属于画布内部辅助控件。所有状态只存在于当前 React 组件生命周期中。

优点是职责清晰、不引入持久化、进入页面时自然恢复默认状态；现有编辑器和分页测量逻辑无需重构。

### 方案 B：统一放入工作台全局状态

将三个显隐状态都提升到工作台页面或 Context 中。它能集中管理状态，但会增加跨组件传参与无关重渲染，对当前局部交互没有收益。

### 方案 C：保留组件挂载，仅使用 CSS 隐藏

通过样式切换工具栏、大纲和分页器的可见性。实现改动少，但隐藏控件仍可能保留在可访问性树或键盘导航中，也不如条件渲染语义明确。

本次采用方案 A。

## 组件与状态设计

### `RevisionWorkspacePage`

新增 `editorToolbarVisible` 页面状态，初始值为 `false`。当 `documentId` 变化时，显式重置为 `false`，保证同一页面实例切换文档后仍符合“每次进入默认隐藏”的规则。

标题栏操作区在模板选择器与导出操作附近增加：

1. “复制简历全文”图标按钮；
2. “显示/隐藏格式工具栏”图标按钮。

工具栏按钮使用现有 ghost 图标按钮。隐藏状态无激活背景；显示状态通过现有激活态语义呈现背景，并同步更新 `aria-pressed` 和提示文本。

页面将 `editorToolbarVisible` 传给 `DraftCanvas`，再由画布传给富文本编辑器。隐藏工具栏时只卸载工具栏视图，不卸载 TipTap 编辑器和文档内容。

### `DraftCanvas`

新增 `pageNavigatorVisible` 状态，初始值为 `false`。`DraftCanvas` 已按 `canvas.document_id` 设置组件 key，因此切换文档时画布局部状态会自然重建。

`outlineVisible` 改为固定的初始值 `false`，不再从本地偏好中恢复可见状态。大纲展开尺寸等内部布局偏好可以继续服务当前会话，但大纲可见性不得跨页面进入持久化。

分页器只有在 `pageNavigatorVisible` 为 `true` 且页面边界已经测量完成时才渲染。现有 `SourceCanvasPageNavigator`、分页 DOM 测量和滚动行为保持不变。

画布将大纲和分页器的当前状态及切换回调传给 `ResumeRichTextEditor`，用于在格式工具栏中渲染对应按钮。

现有自动保存错误提示不得依赖大纲可见性。大纲隐藏且保存失败时，画布在原大纲顶部位置显示紧凑的“保存失败/重试保存”提示；大纲可见时继续使用大纲内部状态区，避免重复反馈。

### `ResumeRichTextEditor`

新增 `toolbarVisible` 属性，默认保持为 `true`，避免影响模板详情等其他编辑器调用方。旧简历重构画布会显式传入页面状态。

现有工具栏继续包含“模块大纲”按钮，并新增“分页器”按钮。两个按钮都使用现有 `ToolbarIconButton`，通过 `isActive` 表达当前显示状态。

当 `toolbarVisible` 为 `false` 时不渲染 `EditorToolbar`，但 `EditorContent`、拖拽句柄和 TipTap 编辑器实例继续正常工作。

## 全文复制

复制源必须是当前画布的最新 `doc_json`，包括尚未完成远端保存但已反映在本地自动保存状态中的编辑内容。

页面使用已有 `resumeDocToPlainText` 将结构化文档转换为纯文本，再调用剪贴板写入能力。复制内容不包含 Markdown 标记、HTML 标签、样式信息或工作区标题等额外元数据。

交互结果：

- 复制成功：显示“已复制简历全文”提示。
- 内容为空：不写入剪贴板，显示“暂无可复制的简历内容”提示。
- 剪贴板写入失败：显示“复制失败，请稍后重试”提示，不影响编辑器状态。

## 可访问性

- 所有新增操作均使用现有 shadcn `Button` 和 `Tooltip` 组合。
- 图标按钮提供明确的 `aria-label`。
- 工具栏、大纲和分页器按钮使用 `aria-pressed` 表达开关状态。
- 隐藏的工具栏、大纲和分页器不留在可访问性树中。
- 复制提示通过现有 toast 系统反馈，不改变键盘焦点。

## 测试策略

### `RevisionWorkspacePage.test.tsx`

- 初次进入时格式工具栏不可见，标题栏显示复制和工具栏切换按钮。
- 点击工具栏按钮后显示格式工具栏，并将按钮标记为激活。
- 再次点击后隐藏工具栏。
- 切换文档后恢复为隐藏状态。
- 点击复制按钮时，剪贴板收到当前简历的完整纯文本。
- 空内容和剪贴板失败时显示对应提示。

### `DraftCanvas.test.tsx`

- 初次渲染时模块大纲和分页器均不可见。
- 显示格式工具栏后，可以通过内部按钮分别显示和隐藏大纲、分页器。
- 分页器重新显示后继续使用已有页面跳转行为。

### `ResumeRichTextEditor.toolbar.test.tsx`

- `toolbarVisible=false` 时不渲染工具栏但保留编辑区。
- `toolbarVisible=true` 时渲染工具栏。
- 分页器按钮正确反映激活态并调用切换回调。

## 验证

完成实现后运行：

```powershell
corepack.cmd pnpm --filter @typedance/web test ResumeRichTextEditor.toolbar.test.tsx DraftCanvas.test.tsx RevisionWorkspacePage.test.tsx
corepack.cmd pnpm --filter @typedance/web build
```

如果本地浏览器允许访问开发地址，再补充一次工作台手动验证；浏览器受策略限制时，以组件测试和生产构建作为交付边界。
