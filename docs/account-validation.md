# 本机账号验收

- 干净安装可创建邮箱密码账号，保存恢复码后可登录，退出并重开会停在登录页。
- 本机账号处于已登录时，完全退出客户端再重开，检查首次显示的正式界面为工作台，并记录耗时。
- 绑定 GitHub 后分别用两种方式登录，确认昵称、头像、账号 ID、简历和对话一致。尝试绑定到第二个本机账号应失败。
- 修改昵称与头像，绑定登录邮箱，设置或重置密码。验证旧恢复码在重置后失效。
- 使用含模板样式、模板示例、简历与模板关联、对话、附件和模型 Key 的隔离旧资料演练升级。核对原目录、备份以及启动后的预览和 PDF 导出。
- 模拟备份失败、旧凭据归属不符和目标目录不可写，检查原资料仍在且应用可重试。
- 正式发布前用生产 OAuth App 验证 GitHub Device Flow，核对签名和发布资产。
