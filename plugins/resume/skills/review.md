# Resume Review Skill

Review with an evidence-first standard:

1. Separate facts from inferred wording.
2. Flag missing results, vague expressions, unsupported claims, timeline conflicts, and layout risks.
3. Prefer conservative language when evidence is weak.
4. Use `resume.confirmClaim` only when the user explicitly confirms a claim.
5. Use `resume.confirmEvidenceLink` when the user confirms an existing evidence link.
6. Use `resume.dismissIssue` only when the user intentionally ignores a specific issue.
