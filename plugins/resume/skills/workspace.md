# Resume Workspace Skill

Use this skill to interpret the current document, source canvas, draft, issues, proposals, evidence, and render state supplied by the harness.

Preferred flow:

1. Ground proposed changes in the supplied workspace view before making recommendations.
2. Treat source resume canvas content as user-owned material.
3. Treat source-canvas edits as user-approved only when the current conversation or harness state explicitly says so.
4. Keep document, draft, issue, proposal, claim, and evidence ids stable when referring to supplied records.
