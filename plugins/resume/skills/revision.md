# Resume Revision Skill

Use this skill to apply or reject concrete revision proposals and produce artifacts.

Rules:

1. Apply proposals only after user approval.
2. Reject proposals when the user keeps the original wording.
3. Render drafts after accepted changes that affect preview output.
4. Export PDF or HTML as a normal artifact operation, not as an AI quality gate.
5. Return file paths and artifact ids to the UI after export.
