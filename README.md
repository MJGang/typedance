# TypeDance

> 用真实材料，完成更可信的职业文档。

TypeDance 是一个以简历改稿为起点的 AI-native 职业文档工作台。

它帮助你把旧简历、项目资料和真实经历，逐步整理成清晰、可信、可持续调整的正式文档。你不需要先学会写 Prompt，也不必把自己的经历交给一次不可控的“AI 生成”；TypeDance 更关心如何理解材料、发现问题、解释修改，并陪你完成可以交付的版本。

## 不是再生成一份简历，而是把改稿真正完成

简历真正困难的地方，往往不是缺少一句漂亮文案，而是：

- 经历和成果散落在旧简历、项目文档、工作总结与记忆里；
- 知道自己做过什么，却不知道哪些内容值得写、应该怎样表达；
- AI 给出了更强的说法，却无法判断它是否真实、是否适合自己；
- 每次面向新机会修改，都容易丢失原有版本和表达重点；
- 内容改完以后，还要重新处理版式和导出。

TypeDance 将这些问题收束到一项连续的改稿任务中：从已有材料出发，形成草稿，识别需要处理的内容，结合你的补充持续修改，最后完成可阅读、可确认、可导出的正式版本。

## 核心产品体验

### 从已有内容开始

你可以导入旧简历，也可以新建一份简历。TypeDance 会把已有内容带入独立工作台，让改稿从真实经历开始，而不是把你留在空白页面前。

### 让资料成为上下文

项目说明、工作记录、过往简历等材料可以作为 AI 的参考上下文。TypeDance 强调资料来源透明、授权范围清楚；本地文件和文件夹只读，不会因为解除引用而被删除。

### 围绕文档持续工作

每份简历都有自己的改稿工作台。文档始终是主角，你可以直接阅读和调整内容，也可以围绕同一份简历保留多轮对话，让后续修改延续已有背景。

### 让 AI 的修改保持可控

AI 可以结合当前文档和已授权资料回答问题、分析表达并协助修改画布。涉及自动修改时，TypeDance 会先请求许可；你始终可以继续编辑、调整方向或重新表达，而不是被一份不可解释的生成结果接管。

### 从内容走到正式交付

在内容之外，TypeDance 也提供简历模板、字体、颜色和段落层级等排版能力。完成修改后，可以将当前版本导出为 PDF 或 HTML，减少在多个工具之间反复搬运内容的成本。

## Resume Pack：为简历场景组织完整体验

Resume Pack 不是模板合集。它是 TypeDance 面向简历场景提供的一套完整产品体验，将简历工作台、资料上下文、AI 对话、版式调整和文档导出组织在一起。

它首先帮助你建立一份能够代表自己的基础简历，再根据具体机会做有针对性的调整。岗位信息很重要，但不应该成为写简历的唯一入口；真实经历和长期可维护的基础版本始终是起点。

## 一次典型的改稿过程

1. 导入旧简历，或创建一份新的基础简历。
2. 添加项目资料、工作记录等可参考内容。
3. 在工作台中阅读当前版本，找出表达薄弱、信息缺失或需要确认的部分。
4. 与 AI 讨论具体问题，并在授权后让它协助修改。
5. 继续手动调整内容和版式，直到文档准确表达你的经历。
6. 导出 PDF 或 HTML，得到可继续使用的正式版本。

## 产品原则

### 真实优先

好的职业表达应该建立在真实经历之上。TypeDance 不鼓励编造经历，也不把空泛但漂亮的措辞当作优化结果。

### 用户掌控

AI 提供理解、建议和修改能力，最终内容仍由用户决定。资料是否加入、AI 是否可以修改、文档如何表达，都应该清楚而可控。

### 本地优先

职业资料通常敏感而私密。TypeDance 默认围绕本机资料与本地工作空间展开，并让外部模型所需的上下文保持透明。

### 文档优先

聊天只是协作方式之一，最终目标始终是完成一份更好的文档。TypeDance 不希望用户停留在无休止的对话里，而是让每次沟通都回到当前稿件。

## TypeDance 适合谁

- 已经有旧简历，但对内容和表达不满意的人；
- 经历真实而丰富，却不知道如何提炼重点的人；
- 希望先维护一份基础简历，再针对不同机会调整的人；
- 在意内容可信度、资料隐私和修改控制权的人；
- 需要持续完成简历、求职信、述职或其他职业文档的知识工作者。

## 当前阶段

TypeDance 正在持续开发中，当前聚焦 Resume Pack 与桌面端简历改稿工作台。现阶段已经围绕简历导入与创建、文档编辑、资料上下文、AI 对话、模板排版和导出形成连续体验；问题卡、证据追踪和更完整的结构化改稿能力仍在持续完善。

简历是 TypeDance 的第一个场景，而不是终点。长期方向是把同样的产品方法扩展到求职信、述职材料、晋升材料、项目总结等更多高价值职业文档。
